fit_4pl.py 
import openfit as of

spec = of.FitSpec(
    model="4PL",
    weights="1/y^2",
    x=conc, y=signal,
)
fit = of.Fit(spec).run()

fit.params["EC50"]     # 18.50 ± 0.62
fit.r_squared          # 0.9994
fit.confint("EC50")    # (17.3, 19.7)

    plate, model="4PL", weights="1/y^2",
)   # delegates to openfit

result = oa.back_calculate(
    plate.unknowns, curve,
    dilution=plate.dilutions,
)

Getting started

Quickstart

Run a full LBA from plate CSV to accepted run report in under ten lines.

Install

$ pip install openassay openfit

End-to-end example

quickstart.py 
import openassay as oa

plate = oa.read_plate("run148.csv")
curve = oa.fit_standard_curve(
    plate, model="4PL", weights="1/y^2",
)

print(curve.r_squared)         # 0.9994
print(curve.lloq, curve.uloq)  # 0.625 640.0

samples = oa.back_calculate(
    plate.unknowns, curve,
    dilution=plate.dilutions,
)
run = oa.evaluate_run(curve, samples, plate.qc)
run.report("report.html")      # carries disclaimer
print(run.accepted)            # True
